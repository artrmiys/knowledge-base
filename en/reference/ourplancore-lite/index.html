    OurPlanCore Lite vs full version¶

    OurPlanCore comes in two versions built from the same code. Estimators run Lite: it has no AI models and no terminal, it is a bit simpler and almost three times smaller. This knowledge base describes Lite. What exists only in the full version is collected in the menu block "AI, terminal and 3D (full version)" or marked on the page with the words "full version only".

    Which version for whom¶

    Version For whom What it gives
    Lite estimators who do not use AI models everything for takeoff and delivery: sheets, tools, the Takeoffs tree, PDF, Excel and Link to Excel; the XL strip with a checkbox in Settings > Modules
    Full those who work with AI the same plus the Claude, Codex and DeepSeek terminal in the window, the AI module, the 3D roof, Workspace for two computers

    Where to get Lite and how it updates¶

    What Where
    The app a single ourplancore.exe file in the shared Dropbox folder Office Folder\programs. It is usually copied to your own computer and run from there; running it straight from the Dropbox folder works too
    Excel templates in the same place, the templates folder: TemplateCom.xlsm, TemplateResidential.xlsm
    What changed in the same place, the changes folder: files Изменения программ <date>.txt ("program changes")
    Update the new file arrives in the same folder through Dropbox and replaces the old one; the previous version is not kept next to it. If you keep your own copy, copy the new file over it after the update
    Version in the window title: OurPlanCore 3.1 - <job>. Since version 3.1 Lite and the full version show the same number, without a -lite tail (before 3.1 it was 3.0.x-lite); how to tell them apart, below

    Lite is built from the same code as the full version, but separately and not with every release. So the Lite number can lag behind, and a new feature from What's new reaches Lite with the next Lite build (except what is cut out, see below).

    Size¶

    ourplancore.exe file Size
    Lite 3.1 (build of 11/17/2026) 92.4 MB
    Full version (3.1, build of 11/17/2026) about 254 MB

    Lite is smaller because its file leaves out the DeepSeek and OpenCode engine, the copy of the knowledge base for the assistant, voice input, Tesseract OCR, the Python libraries for parsing PDFs and images, the TemplateCom.xlsm template, window snapshots for the sample job cards and the .NET language files other than English.

    What Lite does not have¶

    Missing What it is Where it is described
    The >_ terminal the panel with Claude, Codex and DeepSeek to the right of the sheet: the >_ button on the right strip, a palette command, Settings > Terminals AI console
    The AI module AI Inbox, AI Manager, AI crop and markers, AI Fill and Crop Hints, title block reading by the model, tracing requests through the AI Inbox, Settings > AI Crop Notes, palette commands in the AI category AI in the app
    Workspace shared server, second computer, archive of assistant conversations, Settings > Workspace Workspace
    Voice input Settings > Voice Input -
    The 3D module the 3D tab, 3D roof, Roof Base, 3D walls 3D roof, 3D and Massing
    The Materials module the Materials tab: materials from the PDF text Managers
    Create Project Excel Workbook the command that copies the built-in TemplateCom.xlsm into the job folder take the template from the templates folder in Dropbox
    OCR of scans reading the sheet number without a text layer Sheets

    This cannot be turned on: the AI, 3D and Materials modules are not in Settings > Modules, and neither a saved preset nor the job settings will turn them on.

    What Lite has and what works the same¶

    • Sheets, scale, W/F/S/U dots, all measuring tools, the Takeoffs tree, editing and snaps, crops, the Hide mask, overlays, the legend.
    • Detailed sheet rendering, PDF layers, Layer Trace, Count Similar, sheet names and scales from the PDF text: Python and PyMuPDF are kept in Lite for these.
    • PDF export, including the PDF for editing in Adobe (PDF and delivery).
    • Excel: Export > Export Excel to an .xlsx file, the Excel and Value buttons at the bottom (they write from the active cell of the open workbook), Link to Excel, Auto Link, Settings > Excel Links (Export to Excel, Lite).
    • The .ourplan job format is the same: it is one app built with a different switch.
    • Settings > Agent Bridge stayed, but without the terminal the bridge is needed only by an external agent; an estimator does not need it in Lite.

    How Lite differs in daily work¶

    What In Lite
    Settings its own profile %LOCALAPPDATA%\OurPlanCore Lite: settings start from the built-in ones and do not mix with the full version's settings. Logs are in %LOCALAPPDATA%\OurPlanCore Lite\roaming\logs
    .ourplan files Lite does not become the app for .ourplan, a double click on the file does not start it. Open the job from the app (Ctrl+O, the Open project file... link) or drag the file into the window
    Scans no OCR: the name and scale are read only from the PDF text, name a scanned sheet by hand (F2)
    The XL strip off by default. To turn it on: Settings > Modules, check Excel Strip (XL) (together with Excel Integration, which is on from the start). You get the ALL, LG, SF, WL ... ST strip to the right of the sheet, the XLS button on the right command strip, the Settings > Excel Actions and Excel Rules sections; uncheck it and they hide. XL strip
    Both versions on one computer they can be installed side by side: their profiles and settings are separate

    How to tell which version is open¶

    1. Look at the right command strip next to the sheet: Lite has no >_ button. The XL strip with the ALL, LG, SF buttons does not tell the versions apart: Lite can have it turned on.
    2. The window title gives Lite away only before version 3.1: it had a -lite tail (OurPlanCore 3.0.37-lite - <job>). Since 3.1 both versions show just OurPlanCore 3.1 - <job>.
    3. The Lite log is in %LOCALAPPDATA%\OurPlanCore Lite\roaming\logs, the full version log in %APPDATA%\OurPlanCore\logs. The Lite file is about 92 MB, the full version about 254 MB.

    If you need AI models, the terminal or 3D: that is the full version, everything about it is in the menu block "AI, terminal and 3D (full version)", starting with AI in the app.
