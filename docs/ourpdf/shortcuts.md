# Горячие клавиши OurPDF

Здесь: все клавиши OurPDF 0.9.25 с исходными назначениями, по группам; мышь и модификаторы; чем клавиши отличаются от OurPlanCore; как переназначить. "Нет" в колонке клавиши значит, что у команды нет клавиши по умолчанию, её можно назначить в Настройках.

Клавиша не срабатывает, пока фокус в текстовом поле: там буква печатается. Кликните по листу, и клавиши снова работают.

В самой программе ++f1++ открывает панель со всеми действующими клавишами, повторное ++f1++ или ++esc++ закрывает.

## Инструменты и выделение { #tools }

| Клавиша | Действие |
| --- | --- |
| ++v++ | Выделение: обычный режим, выбрать, двигать, править точки; пустое место двигает лист |
| ++e++ | Выделение рамкой: слева направо то, что целиком внутри, справа налево то, что задето |
| ++t++ | Выделить текст PDF: протянуть или двойной щелчок по слову, ++ctrl+c++ копирует |
| ++h++ | Рука: двигать лист |
| ++ctrl+shift+m++ | Измерение (линейка) |
| ++ctrl+6++ | Заметка |
| нет | Ломаная (без замера) |

## Отличия от OurPlanCore { #vs-ourplancore }

Клавиши замеров совпадают: ++r++, ++l++, ++a++, ++j++, ++x++, ++c++, ++f8++, ++f9++, ++d++, ++p++, ++space++, ++ctrl+shift+b++, ++tab++, ++backspace++, ++esc++, ++f1++, клавиши наложения с ++ctrl+alt++. Остальное различается:

| Клавиша | OurPDF | OurPlanCore |
| --- | --- | --- |
| ++v++ | Выделение | Pan |
| ++e++ | Выделение рамкой | Select |
| ++h++ | Рука | спрятать takeoff выделенного |
| ++ctrl+y++ | Повторить | Redo нет |
| ++ctrl+shift+m++ | Измерение | Split |
| ++f3++ | Найти далее | Snap |
| ++f4++, ++f5++ | левая и правая панели | Set Scale, Name / Scale Setup |
| ++f++ | нет (страница целиком на ++ctrl+0++) | Fit: лист целиком |
| ++b++, ++o++ | нет: Beam и Openings в OurPDF нет | Beam, Openings |

Полная таблица OurPlanCore: [Горячие клавиши OurPlanCore](../reference/ourplancore-shortcuts.md).

## Назначить или поменять клавишу { #remap }

1. Откройте Настройки: ++ctrl+comma++ или `Справка > Горячие клавиши и настройки`.
2. Прокрутите вниз до раздела "Горячие клавиши (пусто = по умолчанию, None = отключить)". В каждой строке команда, её исходная клавиша и поле.
3. Впишите в поле сочетание текстом: `Ctrl+Shift+F`, `F3`, `PageDown`. Несколько сочетаний через запятую: `V, E`.
4. Пустое поле оставляет исходную клавишу, `None` отключает команду.
5. Если два действия получили одно сочетание, под таблицей появится "Конфликт сочетаний" с их списком.
6. Нажмите "Сохранить". Непонятное сочетание программа не примет и покажет пример.

Имена клавиш английские, как в колонке исходных: цифра 6 - `D6` (`Ctrl+D6`), плюс и минус - `OemPlus` и `OemMinus`, запятая - `Oemcomma`, Backspace - `Back`, Esc - `Escape`. "Сбросить к умолчаниям" внизу окна возвращает все клавиши (и остальные настройки) к исходным.
