## Режимы просмотра { #view-modes }

Кнопка вида со стрелкой на панели инструментов (как в Acrobat):

| Режим | Клавиша | Как ведёт себя колесо |
| --- | --- | --- |
| Сплошная прокрутка, по ширине | ++ctrl+3++ | все листы лентой; колесо прокручивает, ++ctrl++ и колесо масштабирует |
| По странице | ++ctrl+1++ | по одному листу, как в Acrobat: колесо листает (приближенный лист сначала прокручивается до края), ++ctrl++ и колесо масштабирует |
| Режим чтения | ++ctrl+h++ | прячет панели |
| Полный экран | ++ctrl+l++ | выход ++esc++ |

Прежнее поведение "колесо масштабирует" в режиме по странице включается в Настройках: "Колесо мыши в режиме одной страницы" = "масштаб".

## Масштаб вида и поворот { #zoom }

- Страница целиком ++ctrl+0++, по ширине ++ctrl+2++.
- Крупнее и мельче: ++ctrl+plus++, ++ctrl+minus++, кнопки и поле масштаба в процентах на панели инструментов.
- Правая кнопка мыши по листу: масштабы 25 % - 400 %, "Реальный размер" (100 % = реальный размер листа, как в Acrobat), по размеру страницы, по ширине, по содержимому.
- Шаг колеса задаётся в Настройках: "Зум колесом за щелчок", от 1.05 до 4, как в OurPlanCore 2.
- Повернуть вид: ++ctrl+r++ по часовой, ++ctrl+shift+r++ против. Сам PDF не поворачивается; повернуть страницы в файле можно во вкладке "Страницы" ([Страницы](pages-edit.md#pages-tab)).

## Двигать лист и листать { #navigation }

- Двигать лист: инструмент "Рука" (++h++), средняя или правая кнопка мыши (в любом инструменте), пустое место в режиме "Выделение" (++v++).
- Листать: ++page-up++, ++page-down++; первая и последняя страница ++home++, ++end++.
- Перейти к странице: ++ctrl+g++ или поле номера на панели, можно ввести номер или метку страницы.
- Линейки по краям листа: ++ctrl+alt+r++ или `Просмотр > Показать линейки`.
- Отдельное окно вида того же документа: ++ctrl+shift+n++.
- Левая и правая панели: ++f4++, ++f5++ или стрелки на краях листа.

## Окно Настроек { #settings }

Открыть: ++ctrl+comma++, кнопка-шестерёнка справа на панели инструментов или `Редактирование > Настройки`. Разделы сверху вниз:

| Раздел | Что настраивается |
| --- | --- |
| Язык интерфейса / Interface language | Русский или English; новый язык включается после перезапуска, OurPDF предложит перезапуститься сразу и откроет те же файлы |
| Тема оформления | как в Windows, светлая или тёмная; применяется после перезапуска |
| Память и отрисовка | кэш отрисованных страниц (МБ), кэш миниатюр, ширина миниатюры, обзор страницы (длинная сторона в px), детальный рендер видимой области (Мпикс), соседние страницы заранее, открытых страниц PDFium на документ |
| Работа | шаг зума колесом (как в OurPlanCore: 2), число недавних файлов, показывать аннотации PDF (комментарии, штампы), живые замеры снимков OurPlanCore по умолчанию, предлагать при запуске сделать OurPDF программой по умолчанию |
| Измерение и комментарии | см. таблицу ниже |
| Пометки в самом PDF (Ctrl+S) | принимать пометки из PDF при открытии (замеры, карандаш, текст Acrobat и Bluebeam можно править), резервных копий на файл перед Ctrl+S (1-50), путь к папке копий и сколько там сейчас, кнопка "Открыть папку резервных копий" |
| Редактирование PDF | сдвиг стрелкой и ++shift++ со стрелкой (pt), пауза, в которую нажатия стрелок считаются одной правкой (мс), шрифт замены, шрифт, размер и цвет нового текста, цвет "Закрасить", ширина картинки, поставленной щелчком, максимальный размер картинки, рамка справа налево берёт и задетые объекты (как в AutoCAD) |
| Горячие клавиши | все команды списком: исходная клавиша и поле для своей ([Горячие клавиши](shortcuts.md#remap)) |

### Раздел "Измерение и комментарии" { #settings-measure }

| Поле | По умолчанию | Что меняет |
| --- | --- | --- |
| Единицы замеров | ft-in | ft-in, ft, in, m, cm, mm |
| Точность ft-in: знаменатель дюйма | 16 | 1, 2, 4, 8, 16, 32 или 64 |
| Знаков после запятой | 2 | от 0 до 6 |
| Радиус привязки, px | 10 | от 2 до 40 |
| Измерения остаются на листе как разметка | вкл | выключено: на листе только последний замер, он не сохраняется |
| Орто по умолчанию | выкл | ++shift++ инвертирует |
| Box: площадь, линия и вырез двумя углами | выкл | то же, что ++f9++ |
| Подписи значений замеров на листе | вкл | значения на листе |
| Длины линий (LF) на листе | при наведении | или "всегда подписаны" |
| Значение замера в рамке у курсора при наведении | вкл | рамка как в Acrobat |
| Направляющие у курсора при измерении | вкл | линии как в OurPlanCore |
| Колесо мыши в режиме одной страницы | листает | "листает (Ctrl - масштаб)" или "масштаб" |
| Мост для нейросетей | вкл | агенты Claude и Codex управляют открытым OurPDF; действует после перезапуска ([Управление нейросетями](ai.md)) |
| Цвет замеров | `#D9480F` | квадратик палитры рядом |
| Цвет комментариев | `#E5262B` | |
| Цвет маркера, цвет заметки | `#FFD400` | |
| Толщина линий комментариев, pt | 2 | от 0.25 до 20 |
| Шрифт текста, pt | 12 | от 4 до 96 |
| Автор комментариев | пусто | пусто = имя пользователя Windows |

Толщина, шрифт и прозрачность новых **замеров** (4, 14, 70 %) задаются в карточке справа сверху, пока выбрана линейка ([Вид замеров](measure.md#style)).

### Кнопки внизу

- **Сбросить к умолчаниям** возвращает всё, как было задумано.
- **Сохранить** применяет. Если значение вне допустимого диапазона, программа приведёт его к допустимому и скажет, что поменяла.
- **Отмена** закрывает без изменений.

## Программа по умолчанию для PDF { #default-app }

1. `Справка > Сделать OurPDF программой по умолчанию для PDF`.
2. OurPDF регистрируется для PDF (только для вашего пользователя) и открывает Параметры Windows.
3. Там нажмите "Установить по умолчанию": Windows разрешает это только самому пользователю.

Когда OurPDF уже стоит по умолчанию, пункт меню показывает "OurPDF открывает PDF по умолчанию".
