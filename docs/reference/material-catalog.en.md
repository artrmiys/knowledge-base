# Material catalog

Here: what materials are called in the workbook (the `Mat List` tab) and in column B, so a row reads and orders without questions. Only sizes, grades and families; supplier codes are not in the public knowledge base.

!!! tip "The size is always visible"
    `2x10 P.T.`, `(2) 1 3/4 x 11 7/8 LVL`, `4x8 3/4" CDX`, `7/16" Zip`. Generic words like `lumber`, `trim`, or `I-joist` without a series are not written in B.

## Sawn lumber

| Family | Sizes | Lengths | Where |
| --- | --- | --- | --- |
| **P.T. SYP** (pressure-treated, ACQ .25; `.40` for 4x4 posts) | `2x4` ... `2x12`, `4x4`, `4x6`, `6x6` | `8'` ... `24'` | sill plates on concrete and masonry, deck, balcony, ledger, outdoor posts |
| `2x2 P.T. Clear` | `2x2` | `8'` | balusters |
| **D Fir #2 & Btr** | `2x4` ... `2x12` | `8'` ... `20'` | main framing |
| **D Fir studs precut** | `2x4`, `2x6` x `92-5/8`, `104-5/8`, `116-5/8` | precut | 8', 9', 10' walls; which one to use by wall height: [table](../work/vertical/walls/exterior.md#precut) |
| **KD studs** | same, kiln-dried | precut | where the spec requires KD |
| **MSR** (`1650f-1.5E`, `2400f-2.0E`) | per schedule | | separate row, do not mix with #2 |
| **FRT** | any size marked `FRT` in B | | per construction type (Type III: everything in the exterior wall plane); `FRT` and `FRTW` on a drawing are different labels for the same requirement |

- P.T. bottom plate only on concrete and masonry; on wood floor framing, regular.
- Outdoor posts (porch, balcony, railings) are always P.T.; under a roof, regular.

## Engineered lumber (EWP)

| Family | Sections | Use |
| --- | --- | --- |
| **LVL** (1 3/4" thick) | depth `5 1/2` ... `24` | beams, headers, built-up posts; plies written explicitly `(2)`, `(3)` |
| **LSL** (1.55E), Timberstrand | `1 1/2 x 3 1/2 ... 11 1/2`, `1 3/4 x 11 7/8`, `14` | straight studs, rim, beams |
| **LSL Rim Board** | `1 1/4 x 9 1/2 ... 20` | rim: written `11-7/8" LSL Rim`; with no product on the drawing - `11-7/8" Rim` |
| **PSL** | `3 1/2 x 5 1/4`, `5 1/4 x 7`, `5 1/2 x 11 7/8` | heavy beams and posts |
| **I-joists** | `TJI 110 / 210 / 230 / 360 / 560`, `LPI 18 / 20 / 32 / 36 / 56`, `BCI`, `RED-I` x `9 1/2`, `11 7/8`, `14`, `16` | the series stays in B: the hanger depends on it |

- Scope `EWP by others`: LSL, LVL, I-joists and rim are not counted, but the note `Note: All EWP products are by others.` goes in the header.
- With I-joists, engineered rim only; LVL rim only when a deck or corridor attaches to it.
- Type III: LVL, PSL, LSL are not allowed in the exterior wall plane, do not write `LVL FRT`.

## Sheathing, decking, barriers

| Material | Thicknesses | How to write it |
| --- | --- | --- |
| Plywood, CDX | `1/2`, `15/32`, `19/32`, `5/8`, `3/4` | `19/32" Ply`; `19/32 = 5/8`, not `1/2`. `CDX` only if the spec says so |
| OSB | `7/16`, `15/32`, `1/2`, `5/8` | `7/16" OSB`; `LP FlameBlock` is not `7/16 OSB FRT` |
| Zip, Zip R | `7/16`, `1/2`, `5/8`; `R-3`, `R-6`, `R-9` | `7/16" Zip R3` + `Zip Tape`; `7/16" Zip` on S and `Zip R-3` on A are one product |
| Subfloor | `3/4" T&G` (AdvanTech), `5/8` SE; `1/2" underlayment` | `3/4 Ply` under tubs, not under showers; new subfloor over existing per detail |
| Gypsum sheathing | `5/8" DensGlass`, `1/2" Durock`, `5/8" Type X ext.` | layers per the detail arrows: a double arrow = two layers |
| Shaft liner | `1" Shaft Liner` + `CH` / `J` or `H` / `C` channels | makeup per wall type |
| WRB | per spec: `Tyvek`, fluid-applied barrier | in the workbook the row is `Vapor Barrier` (template name); on the drawing it is WRB / Air Barrier, not a vapor barrier |
| Insulation | `R-6`, `1"`, `1 1/2"`, `2"` rigid; tapered on a flat roof | only exterior, outside the sheathing; interior insulation and sound batt are not counted in frame scope |
| Membrane | `EPDM`, `Ice & Water`, `Felt 15#`, `1/4" DensDeck` cover board | roofing per the section |

A conflict between arch and S on sheathing is resolved with a note: [Notes in DFL](standard-notes.md#spec-cells).
