# Формулы и факторы

Здесь: множители и формулы колонки C, которые стоят в книге, и чем studs отличаются от joists. Формулы даны в английской локали (`CEILING`, `EVEN`); в русской Excel показывает их как `ОКРВВЕРХ`, `ЧЁТН` с `;` между аргументами, смысл тот же.

## Обозначения { #legend }

Буквы в формулах - это колонки одной строки DFL. Одна строка = одна позиция материала.

| Буква | Что это | Пример |
| --- | --- | --- |
| `G` | Замер из OurPlanCore: длина линии в футах, площадь в квадратных футах или число точек. Серая колонка справа от таблицы, в заказ не идёт. Запаса в `G` нет: это чистый замер. | `G` = 186 (длина наружных стен) |
| `H` | Второе число строки, тоже серое. Смысл зависит от строки: шаг в дюймах (крепёж и blocking по шагу), число слоёв у подписи с `(n)` (plates, headers, rim), высота стены в футах (studs, shear walls). У каждой формулы ниже сказано, что стоит в `H`. | `H` = 48 (анкеры на 48" o.c.) |
| `C` | Количество в заказ. Формула от `G` (и `H`, `D`), руками число не пишут. | `=CEILING(G/D,1)` |
| `D` | Единица: `LFT`, `SQ FT`, `4x8`, `pcs`, `unit`, `tubes`. У леса, который заказывают штуками (studs, joists, beams, posts, headers, rim, ribbon, blocking, ledger, bracing), в `D` стоит длина доски в футах: 8, 10, 12, 14, 16. Тогда `C` - число досок, и формула делит на `D`. | `D` = 16 |
| `Stock LF` | Длина заказной штуки в футах, то же число, что в `D`. У профилей shaft обычно 12. | 12 |
| `LFT`, `SQ FT` | Погонные и квадратные футы. Так и пишутся в `D`; `LF`, `SF`, `SQFT` в `D` не пишут. | |

Как устроена строка и остальные колонки: [DFL: как устроена книга](dfl-overview.md).

!!! warning "Stud и Joist считаются по разным таблицам"
    У studs и joists один и тот же `o.c.`, но разные множители: studs по правилу владельца (стойка на фут плюс waste), joists по геометрии (`12 / spacing`). Не путать таблицы.

## Stud spacing factors { #stud-spacing-factors }

Канон по стойкам. На `16" o.c.` считается одна стойка на фут стены плюс 10 процентов waste, а не геометрические `0.75`: так покрываются углы, T-пересечения, jack, king, cripple у проёмов и обрезь.

| Spacing | Фактор (pcs / LFT) | Откуда |
| --- | ---: | --- |
| 12" o.c. | **1.4667** | 1:1 с масштабом 16 к 12 (x1.333) плюс 10% waste |
| 16" o.c. | **1.1** | 1:1 плюс 10% waste |
| 24" o.c. | **0.625** | 0.5 плюс 25% waste |

- `pcs = wall LFT x фактор`, в книге `=G*фактор`.
- Высота в строке студов (E, до 1/8") и в имени стены - это высота стены в сборе, вместе с plates: floor-to-floor минус subfloor `3/4"`, минус глубина перекрытия. Одна нижняя и две верхние plates **не вычитаются**: по этой высоте шаблон сам выбирает стойку, precut или full height. Вычитаются только лишние доски сверх этих трёх, если их показывает разрез (вторая нижняя plate, blocking под фермами). Чистая стойка короче высоты стены на `4 1/2"`. Таблица выбора стойки: [Exterior Walls](../work/vertical/walls/exterior.md#precut).
- Bearing walls как Extra: основная линия с обычным фактором, лишние plies отдельной строкой `double extra`, базу вычесть из обычных studs. Факторы Extra: `12" o.c.` 1, `16" o.c.` 0.75, `24" o.c.` 0.5 (без waste базовой строки).
- Double стена = два каркаса только если на плане два каркаса; staggered corridor 2x4 = два ряда на 16" o.c., plates 2x6.

## Joist spacing factors

Joists, rafters и floor trusses - по истинной геометрии center-to-center, без stud-waste.

| Spacing | Фактор (pcs / LFT ширины) |
| --- | ---: |
| 12" o.c. | **1.0** |
| 16" o.c. | **0.75** |
| 19.2" o.c. | **0.625** |
| 24" o.c. | **0.5** |

- `pcs = ширина пролёта LFT x 12 / spacing + 1` (торцевой joist на каждый run).
- Из OurPlanCore joists приходят парами "число / длина" из J Area: одинаковые длины складываются, длина больше 8' и нечётная получает +1 (правило `C_JoistsSort`); короткие до 7' идут на двойную доску (`90 x 6'` = `45 x 12'`, в E `90 pcs 6'`). Extra той же длины прибавляется к основной строке.
- Hangers по joists: на оба конца каждого joist, по сборкам; штучный крепёж меньше 50 - до чётного.

## Rim, ribbon, blocking, ledger

В дереве каждая такая деталь - одна линия (Line) по месту применения, её длина в футах уходит в `G`. Как длина превращается в заказ, зависит от строки и типа работы.

| Строка | Где | C | D |
| --- | --- | --- | --- |
| `Rim Board`, `Ribbon Board`, `Blocking`, `Blocking for Drywall`, `Ledger` | Floor и Roof Framing List обычной книги (Frame, COM, residential) | `=CEILING(G/D,1)` | `16` |
| `Rim Board (2)` | то же, двойной rim | `=CEILING(G*H/D,1)`, H = 2 | `16` |
| `Rim Board` | EWP-only заказ (считаем только engineered) | `=CEILING(G*1.05,1)` | `LFT` |
| `Blocking` непрерывный | EWP-only заказ | `G` без фактора | `LFT` |
| `Blocking` в стенах | Floor Walls | `=EVEN(G)` | `LFT` |
| `Bracing Ext Walls`, `Bracing Corridor`, `Bracing Demising` | Floor Walls | `=G/8*1.1`: одна доска на 8 LFT стены | длина доски по высоте стены |

- В обычной книге строки rim, ribbon, blocking и ledger пишет макрос `C_RimBoardBlockingHangers`: количество в досках по 16'. Отдельного фактора нет, запас даёт округление вверх до целой доски.
- `1.05` - фактор rim только на EWP-only заказах: там rim остаётся в LFT и на куски не делится. Если клиент просит rim в LFT на обычном заказе, фактор `1.1`.
- Линию в дереве на куски по 16' не режь: меряется вся длина узла, на доски делит формула.
- Длина доски bracing стен: стена до 10' - `14`, до 12' - `16`, до 16' - `18`, выше - `20`. Формула в `D` шаблона ставит её сама по самой высокой стене группы. Стены ниже 7' bracing не получают.
- Top chord bearing trusses: вместо ribbon board blocking между фермами, часто `(2) 2x6`.
- Blocking по шагу считается кусками: формулы ниже.

## Blocking formulas { #blocking-formulas }

Blocking по шагу - короткие куски между joists или фермами, которые стоят через равные промежутки вдоль линии. `G` - длина этой линии в футах, `H` - шаг в дюймах, `D` - длина доски (16).

```excel
Blocking 48" o.c., flat       = CEILING(G * 12 / H * 2 / D, 1)
Diagonal Blocking 48" o.c.    = CEILING(G * 12 / H * 3 / D, 1)
Blocking btw trusses (n)      = CEILING(G / D, 1)        G = длина линии x число рядов n
T blocking at gables          = EVEN(G / D)
```

Как читать первую формулу: `G * 12 / H` - сколько точек с blocking помещается на линии; `2` - сколько футов доски уходит на одну точку; получились погонные футы; `/ D` - доски по 16'. Пример: линия 96', шаг 48": 96 x 12 / 48 = 24 точки, 24 x 2' = 48 LFT, 48 / 16 = 3 доски.

### Blocking factor по типу { #blocking-factor }

Сколько футов доски уходит на одну точку:

| Тип | Футов на точку |
| --- | ---: |
| Flat | `2` |
| Diagonal (строка `Diagonal Blocking 48" o.c.`) | `3` |
| Vertical | `1.5` ... `2` |

Число из детали главнее: если деталь показывает другое число кусков в точке, множитель берётся по детали.

Стены 10' и выше - два ряда blocking. Kitchen: `2x6`, 4 штуки по 14' на кухню; bath: 1 штука по 14' на ванную. Kickers только там, где они есть на детали.

## Формулы колонки C по типу строки

| Тип строки | C | D |
| --- | --- | --- |
| Листы 4x8 (обшивка, subfloor) | `=CEILING(G/32*1.1,1)` | `4x8` |
| Лес штуками по длине доски (rim, ribbon, blocking, ledger, sub fascia) | `=CEILING(G/D,1)`: длина в футах делится на длину доски | длина доски, обычно `16` |
| Погонаж без деления на доски (flashing, tape, jambs, blocking в Wall Materials) | `=CEILING(G*1.1,10)`; меньше 50 - `=CEILING(G*1.1,2)` | `LFT` |
| Plates | `=EVEN(G*H*1.1)` (H = число plates из подписи: `(1) btm`, `(2) dbl top`) | `LFT` |
| Studs | `=G*1.1` на 16" o.c. (фактор из таблицы выше) | длина стойки: `8`, `9`, `10`, `12` |
| Крепёж по шагу (anchors, ties, hangers) | `=CEILING(G*12/H*1.1,2)` (H = шаг в дюймах); при 50 и больше родная значимость `,10` или `,1` | `pcs` |
| Screws по фермам | `=CEILING(...,3)` | `pcs` |
| Washers | `=C<строка анкеров>` или `=SUM(...)` одной строкой на группу | `pcs` |
| H-clips | по толщине настила и шагу опор: `PSCL at 16"` = 6 на лист, не "4 на лист"; при T&G и настиле толще порога спецификации не нужны | `pcs` |
| `Bracing for Trusses` (фермы перекрытия) | `2x6`; `=CEILING(G/D,1)`, `G` = длина линий bracing в футах: одна линия поперёк ферм примерно каждые 10'; не над несущими стенами и не там, где joists/rafters stick или TJI (только фермы) | `16` |
| `Truss Bracing` (фермы крыши) | `2x4`; `=CEILING(G/4/D,1)`, `G` = площадь в плане под фермами крыши, включая гараж; stick-кровля строку не получает | `16` |
| Panel adhesive | `=CEILING(C<subfloor>/3,1)`: одна туба на 3 листа subfloor | `tubes` |
| Resilient channels | `=CEILING(area*12/spacing*1.1,10)`, только где показаны в типе стены | `LFT` |
| Holdowns | `=G` к бетону, `=G*2` через деревянное перекрытие | `pcs` |
| Двусторонний shear wall | G = сумма двух лиц, без ещё одного x2 | `4x8` |

### Truss bracing: откуда числа { #truss-bracing }

Это две разные строки, и считаются они по-разному.

- **Перекрытие, `Bracing for Trusses`.** В дереве рисуются сами линии bracing (strongbacks): `framing/<этаж> framing/details/bft`, одна линия поперёк ферм примерно каждые 10' пролёта. Над несущими стенами линию не ведут. Там, где перекрытие из stick joists или TJI, bracing нет вообще: он нужен только фермам. Пример: пролёт ферм 28', две линии по 48' = 96 LFT; `=CEILING(96/16,1)` = 6 досок `2x6` по 16'.
- **Кровля, `Truss Bracing`.** Линии не рисуются, берётся площадь в плане под фермами: 1-й этаж плюс гараж и нижние крыши, если фермы стоят и над ними. `G/4` - это погонные футы bracing: один ряд на каждые 4' длины фермы, то есть на квадратный фут плана уходит 1/4 фута доски. `/D` - доски по 16'. Пример: дом 1 800 SQ FT и гараж 440 SQ FT: 2 240 / 4 = 560 LFT, 560 / 16 = 35 досок `2x4`.
- Если на плоской кровле линии bracing ферм нарисованы и замерены (`framing/roof framing/details/bft`), они идут строкой `Bracing for Trusses` в Roof Frame list, и строка по площади для этих ферм не нужна. Одно и то же дважды не считают.

Формулы смотрят на свой блок: свой header, свой множитель units, свой этаж. Скопированный этаж со ссылками в чужой блок - самая частая ошибка книги.

## Кровля

Уклон применяется один раз: площадь в плане x `sqrt(1 + (rise/12)^2)`.

| Pitch | Фактор |
| --- | ---: |
| 4/12 | 1.054 |
| 6/12 | 1.118 |
| 8/12 | 1.202 |
| 12/12 | 1.414 |

Уклон из листа, у каждого корпуса свой (гараж 4/12 при доме 6/12). Число в имени `rf 6` - это rise на 12.

## Округление

| Что | Правило |
| --- | --- |
| Штучный крепёж меньше 50 | вверх до чётного (significance 2) |
| 50 и больше | значимость шаблона: `,10` большие ties и screws, `,1` листы и рейки |
| Строки в `LFT` и `SQ FT` | `G*1.1` вверх: меньше 50 - до чётного, 50 и больше - до 10 |
| Доски, листы, трубы | целыми вверх; `2.75` и `9.6` в C не бывает |
| Waste | один раз, в формуле `C`. В `G` запаса нет |

## Shaft Walls { #shaft-walls }

Shaft walls отдельным блоком, даже когда стены дома идут панелями by others. Материал из wall type и детали: бывают `2-1/2"` CH + J-channel и `2"` H + C-channel. Две системы в одной стене не смешивают.

Панели и вертикальные профили считаются от **площади** стены, горизонтальные - от длины:

- `Area` (это `G` строк панелей и вертикальных профилей) = длина shaft-стен x высота, сумма по этажам, в SQ FT;
- `24` = площадь одной панели `2' x 12'`; в E строки пишется `2x12 Panels`;
- `0.5` = вертикальный профиль каждые 24": один на 2' стены, высотой во всю стену;
- `Run LFT` = длина shaft-стен; `x 2` - профиль сверху и снизу на каждом этаже;
- `Stock LF` = длина штуки, обычно 12 (стоит в `D`).

```excel
2-1/2" CH + J (shaft, панели с одной стороны):
Linear Panels, 1" Shaft Panels   = CEILING(Area * 1.1 / 24, 2)
CH Channels Vertical             = CEILING(Area * 0.5 * 1.1 / Stock LF, 2)
J Channels Horizontal            = CEILING(Run LFT * 2 * 1.1 / Stock LF, 2)

2" H + C (area separation wall, панели с двух сторон):
Linear Panels, 2 слоя            = CEILING(Area * 2 * 1.1 / 24, 2)
Channels Vertical (H)            = CEILING(Area * 0.5 * 1.1 / Stock LF, 2)
Channels Horizontal (H)          = CEILING(Run LFT * 2 * 1.1 / Stock LF, 2)
Channels Perimeter (C)           = CEILING(Perimeter LFT * 1.1 / Stock LF, 2)
```

Пример: shaft 64 LFT, высота 10.5'. Площадь 64 x 10.5 = 672 SQ FT. Панели: 672 x 1.1 / 24 = 30.8, это 32 панели. CH: 672 x 0.5 x 1.1 / 12 = 30.8, это 32 штуки по 12'. J: 64 x 2 x 1.1 / 12 = 11.7, это 12 штук.

!!! danger "Не дели на 24 длину стены"
    Если в формулу панелей подставить длину (64 LFT) вместо площади, выйдет 4 панели вместо 32: недосчёт во столько раз, сколько футов в высоте стены.

Dropped ceiling metal joists: `12" C-type = Area * 0.75 * 1.1`, в LFT.

## Проверка порядка величин

Число выглядит странно - сравнить с типичным для похожего дома: [Ориентиры количеств](quantity-benchmarks.md). Это проверка разумности, не норма; расхождение значит "открой деталь и единицы", а не "исправь на среднее".
