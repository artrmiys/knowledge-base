# OurPlanCore - решение проблем

Здесь - симптом, причина и что сделать, для OurPlanCore 3.0. Нужно, когда программа ведёт себя не так, как ждали: пропало, легло не туда, тормозит, не сохраняет. Начинайте с таблицы своего симптома.

## Пропали листы или takeoff {#missing}

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| На листе нет замеров, в дереве они есть | takeoff спрятан клавишей ++h++ или точкой видимости листа | переключатель видимости у takeoff в Takeoffs или точка видимости у листа в Pages (`Show all takeoffs on <лист>`) |
| Нет целого takeoff после Merge | он влился в выживший | ++ctrl+z++ с фокусом в Takeoffs или ПКМ `Undo Takeoff Merge / Split`; копия в `AI_Context/takeoff-merge-trash` |
| Пропала папка после правки агентом | удалена через Agent Bridge | `agent_bridge.py undo` или папка `AI_Context/agent-trash` |
| Лист исчез после сортировки | Sort A/S или D/Sec/WT переложил его | `Open / Import > Undo Last Page Sort`; поиск по листам в Pages |
| Удалили лист или позицию случайно | | ++ctrl+z++ в том же дереве возвращает последнее удаление; `Delete Empty` тоже откатывается |
| Замеры есть, легенда пустая или не та | другой порядок или группы легенды | ПКМ по листу: `Reset Sheet Legend Order`, `Organize > Legend Groups...` |
| После отката на `.bak` пропали кропы и маски | EXE до 2.2.34 читает их как линейную разметку и теряет при сохранении | не сохранять проект старым EXE; вернуть 3.0 и открыть копию до сохранения |

## Takeoff лёг не в ту папку {#routing}

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| В статусе нет `Route:` | у листа нет точки W/F/S/U | поставить точку под заголовком Scale или `Settings > Sheet Takeoff Routing > Route sheets without a dot now` |
| `Route sheets without a dot now` точку не поставил | имя листа с тегом из Skip tags (`sec`, `el`, `d`, `rcp`...), два тега уровня (`1st 2nd`) или `u` не последнее слово | поставить точку рукой или переименовать лист |
| Takeoff ушёл в другой корпус | зелёная точка стоит на другой папке | в заголовке Takeoffs нажать красную точку (корень) или выделить нужный корпус и зелёную |
| `eve` или `gable` легли не по точке листа | правила имени сильнее точки | так задумано; менять в `Settings > Takeoff Name Routing` |
| Count на W-листе лёг в `walls/...` | по умолчанию так | holdowns ставить на S-листе или добавить правило имени |
| Новый takeoff не создаётся, сообщение про root | зелёная точка указывает на удалённую папку | нажать красную точку и выбрать корпус заново |
| Копия при вставке легла в другую подпапку | галка `Copies keep their source folders` | в `Settings > Sheet Takeoff Routing` включить или выключить, проверить строку `Root:` в диалоге вставки |

Разбор правил - [Маршрутизация takeoff](ourplancore-routing.md).

## Медленно {#speed}

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| Зум дёргается на большом пустом листе | исправлено в 2.2.39-2.2.42 | обновиться до 3.0; проверить версию в заголовке окна |
| Тяжёлый PDF-лист открывается долго | растр не подготовлен | Sheet Manager: выделить, PNG и DPI, `Prepare`, потом `First On`; или `Display > Static image` |
| Медленно после открытия проекта | фоновый прогрев страниц | `Settings > Defaults > Warm all job pages in background` выключить (по умолчанию выключено) |
| Тормозит переключение листов, дерево или Save | разные причины | запомнить именно эту операцию и версию; в логе программы при медленных кадрах есть строки `Viewport slow frame` с таймингами |
| Name по всему комплекту долго | один лист в комплекте 127 страниц читается около 12 с | это норма; запускать на папке, не по одному листу |

## Сохранение, открытие, версия {#save}

| Сообщение или ситуация | Причина | Что сделать |
| --- | --- | --- |
| `Saved in local recovery` | пакет `.ourplan` ещё не обновлён | нажать `Save` и дождаться `Save: Saved hh:mm:ss` перед копированием файла |
| `Job Is Already Open` / `This job is owned by another OurPlanCore instance` | проект открыт во втором окне или на другом компьютере (Workspace) | закрыть второе окно; в Workspace дождаться синхронизации, не открывать одновременно |
| Save падал после переноса листа в другую папку | исправлено в 2.2.16 | обновиться |
| Проект лежит в папке облачной синхронизации, Save или открытие спорят с ней | синхронизатор подменяет или блокирует файл | держать рабочий проект в `Desktop\OurPlanCore Jobs`, в облако копировать после Save; при сообщении о внешнем изменении сохранить свою версию через `Save As` |
| Повреждённый JSON метаданных | | `Open / Import > Project Data Recovery...`: запись из списка, `Retry reading` или `Restore from copy...` |
| Сам `.ourplan` не читается | | открыть предложенную local recovery; Recovery не ремонтирует ZIP или PDF |
| Прерванная операция с листами | | журнал `.undo/operations`: `Undo Last Page Operation` |
| Недостаточно места | распакованный проект больше свободного места | освободить место вне проектов и recovery |

### Какая версия запущена {#version}

Версия написана в заголовке окна: `OurPlanCore 3.0.0 - <проект>`, и в строке `Version ...` лога программы. Установка одна: папка обновлений `Desktop\updates\OurPlanCore`, откат - файл `.bak` рядом с EXE (в имени файла стоит версия, например `ourplancore.exe.2.2.42-....bak`). Старый отдельный Preview больше не используется. Если функция из [Что нового](ourplancore-changelog.md) не работает, сначала сверьте версию в заголовке.

## Терминал, Agent Bridge, Workspace {#terminal}

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| Ассистент пишет `context_unavailable` | исправлено в 2.2.36 для листов с кропами и разметкой | обновиться; кнопка `Context` открывает файл, в нём должно быть `state: open` |
| `Run` не запускает терминал | нет Git Bash или ярлыка ассистента | установить Git Bash, войти в CLI один раз; при Workspace ярлык не нужен |
| Агент не видит проект | мост выключен или проект read-only | `Settings > Agent Bridge > Enable local assistant access`; `agent_bridge.py sessions` |
| Агент ответил таймаутом | исход неизвестен | не повторять запрос с новым ID; `inspect` и проверить дерево |
| `Synchronization is running` | идёт синхронизация | подождать и повторить `Sync now` или `Share current saved project` |
| Конфликт версий проекта | правили на двух компьютерах | `Settings > Workspace > Review conflicts`: `Keep this computer`, `Use server version` или `Open preserved files` |

## Конвейер и Job Tracker {#cli}

| Сообщение | Что сделать |
| --- | --- |
| `Refused to ...: OurPlanCore is running. Close it first.` | конвейер меняет пакет только при закрытой программе: закрыть окно и повторить |
| `'<имя>' has no leading project number (expected 'NN. Name')` | переименовать проект в `NN. Name`; кнопка `In Progress` берёт номер из имени |
| Нет кнопки `In Progress` | `Settings > Modules`, модуль Job Tracker |
| Экспорт PDF по корпусам дал один файл | зелёная точка не выбрана или стоит красная; либо запуск с `--grouping single` | поставить зелёную точку на корпус, сохранить, повторить |

## PDF и Excel {#pdf}

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| В PDF нет кропа, в логе `Crop skipped on '<лист>'` | лист-источник кропа удалён | удалить кроп или вернуть лист; кроп с красным крестом найти на листе |
| Маска Hide или кропы не печатаются | выключен модуль Annotations | включить модуль; Markups отключать можно |
| Линии в PDF закрывают чертёж | | `PDF Output > Opac` меньше 100 |
| PDF выглядит не как экран | лента Viewport настраивает экран, PDF Output - вывод | `PDF Output > Preview` перед экспортом |
| Excel: `ALL` остановился | нет однозначного корня корпуса или шаг не выполнился | поставить зелёную точку; шаги, которые не выполнились, перечислены в предупреждении; второй прогон шаблон не портит |
| Excel получил лишние строки | другая книга, лист или ячейка активны | проверить активную книгу и ячейку; `Value` пишет в активную ячейку |
| Заметки не попали в Excel | точка "комментарии" на кнопке Excel выключена | закрасить точку и повторить экспорт |

## Кнопка или клавиша не работает

| Симптом | Что проверить |
| --- | --- |
| Нет вкладки или кнопки | `Settings > Modules`: модуль включён, проектная копия не выключает его |
| Клавиша печатает букву | фокус в текстовом поле: ++esc++ и клик по листу |
| Назначение не срабатывает | [редактор клавиш](ourplancore-shortcuts.md#remap): контекст команды и конфликты |
| Правка заблокирована | проект read-only или открыт другим окном |
| Mirror недоступен | выделить подходящие замеры; зеркало выбранных объектов и переворот листа - разные команды |
