# Ориентиры количеств

Здесь: типичные значения из сданных работ, чтобы заметить число не того порядка. Это проверка разумности, не норма: расхождение значит "открыть деталь, единицы и scope", а не "подогнать к среднему".

## Как пользоваться

1. Посчитал позицию - сравни с типичным для похожего дома и scope.
2. Выпало из диапазона - проверь единицы (LFT или pcs), шаг, множитель units, этаж, двойной waste.
3. Причина найдена и это особенность проекта - оставь, при необходимости с нотой.

## Множители (канон в Формулах)

| Фактор | Значение | Где |
| --- | --- | --- |
| Studs 16" o.c. | x1.1 | стойка на фут плюс 10% waste |
| Studs 24" o.c. | x0.625 | 0.5 плюс 25% waste |
| Joists | 12 / spacing + 1 | без stud-waste |
| Waste общий | x1.1 | один раз в формуле |
| Rim EWP | x1.05 | только EWP-jobs; остальные x1.1 |
| Bracing стен | 1 на 8 ft | внутренний ориентир |

Источник множителей - [Формулы и факторы](formulas.md).

## Типовые длины стока

| Позиция | Обычно | Заметка |
| --- | --- | --- |
| Beam | 12' (8 ... 16) | пилёный 8 / 10 / 12 / 14 / 16; длина из имени в программе |
| Joist | 12' (10 ... 16) | короткие до 7' на двойную доску |
| Stringers | 10' (10 ... 14) | наклонная плюс опирание: 10.0' = 12' |
| Treads, risers | 12' | |
| Sub fascia, truss bracing | 16' | |
| Posts deck, porch | 10' (8 ... 10) | 6x6 P.T. |
| Blocking | 16' / 8' | stick |

## Типовые количества

| Позиция | Типично | Как читать |
| --- | --- | --- |
| Foundation anchor bolts | около 66 (34 ... 180) | шаг из anchorage schedule; SW отдельно |
| Foundation washers | около 120 (50 ... 224) | одна на болт; две при дереве с обеих сторон |
| Termite shield | 350 LFT (200 ... 600) | периметр фундамента |
| Beams на этаж (Wall Materials) | 3 (2 ... 4) | марок, не штук |
| Hangers в Wall Materials | 16 (5 ... 62) | только построчные hangers, joist hangers отдельно |
| Decking posts | 4 (2 ... 8) | на балкон 2, угловой 1 |
| Sub fascia на плоской кровле | 27 (18 ... 38) | штук по 16' |

## Соотношения между похожими корпусами

У однотипных корпусов объёмы на 1000 SF пола держатся постоянными: выброс у одного корпуса - флаг. Проверять обшивку, window и sill flashing, WRB, insulation, draft stop, clips, анкеры; площадь на unit и балконы на unit; porch = balcony при porch над балконом. Loft и attic: subfloor по полному footprint, не только по проходимой площади.

## Примеры, когда число выпало и было ошибкой

| Что увидели | Причина |
| --- | --- |
| Clips в 1.5 раза больше листов x 4 | считали 4 на лист вместо шага опор; или clips при T&G |
| Обшивка кровли гаража на 3 листа больше | уклон 6/12 вместо 4/12 с листа |
| Ties 180 при 390 LFT опирания | не все линии опирания |
| Балконный decking 900 SF при блоке на 60 | множитель units из чужого блока |
| Hangers 154 при 106 joists | по закупочным доскам, а не по сборкам |
