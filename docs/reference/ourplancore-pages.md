# Листы (Pages)

Здесь: панель Pages, папки листов, имена и масштаб по всему комплекту, сортировка, точки W/F/S/U, видимость, закладки и слои PDF. Нужно в начале каждой работы и когда новый замер лёг не в тот этаж.

## Панель Pages

| Кнопка | Что делает |
| --- | --- |
| `Open` | открыть выделенные листы: `Open as Tabs` или `Detach to windows`; `Tile M2` раскладывает окна на второй монитор |
| `Folder template` | `Auto`, `COM`, `EWP`: набор стандартных папок для `Auto Folders` и `Auto Tree` |
| `+ New` | `New Folder`, `Blank Sheet`, `Auto Folders` |
| `Setup` | `Name / Scale...` (`F5`), `Sort: A > Arch / S > Struct`, `Sort: D / Sec / WT suffix`, `Repair page links` |
| `New Folder`, `Name`, `Scale`, `Name+Scale` | папка под выделенной; автоимя, автомасштаб или оба для выделенных листов или папки |
| Поиск | по имени папки (с переключателем регистра) и по имени листа |
| Под-вкладки | `Pages`, `PDF Layers`, `Overlay`, `Bookmarks`; сюда же стыкуется `Templates` |

Клавиши в дереве: `F2` переименовать, `Ctrl+D` дублировать, `Ctrl+C` / `Ctrl+X` / `Ctrl+V`, `Ctrl+Up` / `Ctrl+Down` порядок, `Delete`, `Ctrl+Z` вернуть удалённое, `F4` масштаб выделенных листов.

## Папки листов

Канон папок и тегов имён - [Дерево takeoff и имена листов](../start/takeoff-structure.md). Коротко: `00. imported/` с подпапками `Arch`, `Struct`, `sections`, `details arch`, `details struct`, `rcp`, `units`, `demolition`; ненужное в `--------others`; у каждого корпуса своя папка с тем же именем, что в Takeoffs; ревизия - `01. old/` и `02. NEW SET <дата>/`.

1. `+ New > Auto Folders` создаёт стандартные папки по `Folder template`.
2. Листы раскладывает `Setup > Sort: A > Arch / S > Struct` (по букве номера) и `Sort: D / Sec / WT suffix` (по последнему тегу имени: `d`, `sec`, `wt`, `rcp`, `u`...). Создаются только непустые папки.
3. Руками: перетащить лист, или ПКМ `Move to Folder...`, `Cut` / `Paste Into Folder`.
4. Ошибся - `Open / Import > Undo Last Page Sort`.

Лист с именем, оканчивающимся на `-`, при сортировке уходит в `--------others` (правило в `Settings > Sort A/S`). ПКМ по папке: `Organize` (сортировки, легенды, Repair Measurement Links), `Metadata` (анализ PDF, автоимена, выученные правила), `Batch Overlay...`, `Open in Explorer`.

## Имена листов: Name, Scale, Name+Scale

<figure markdown>
  ![Меню Metadata и диалог предпросмотра имён](../assets/images/ourplancore/v3/pages-metadata-menu.png)
  <figcaption markdown="span">Предпросмотр перед применением: предложенное имя, действие по масштабу, уверенность и причина. Непонятное снять галкой.</figcaption>
</figure>

1. Выделить папку `00. imported` (или листы) и нажать `Name+Scale` (`Name` и `Scale` работают по отдельности; те же кнопки на ленте Main при модуле Sheet Manager).
2. В диалоге проверить колонки `Proposed Name`, `Scale Action`, уверенность и `Why`. `Rename All` / `Scale All` ставят галки всем, `Clear` снимает.
3. `Apply`. Имя получает формат `<номер> <тег>` строчными: `a101 1st`, `s201 2nd`, `a105 rf`, `a8.01 1st rcp`, `ad101 demo`, `a3011 u`. Одновременно лист получает точку W/F/S/U (см. [ниже](#dots)).
4. Что не распозналось, назвать руками: `F2` на листе, `Page > Batch Rename` для серии, или `Setup > Name / Scale...`.

Что читает программа: номер листа по профилю всего комплекта (место штампа, подпись `SHEET NO.`, индекс листов); текст, повторяющийся на всех листах (фирма, телефон), номером не считается. Сканы без текстового слоя читаются встроенным OCR. Лист, который текст не назвал, может прочитать модель по картинке штампа: галка `Read title blocks the PDF text cannot name with AI` в `Settings > Auto Rename / Scale` (нужен модуль AI и ключ, операция онлайн). Имена, которые ты оставил при открытии проекта, программа запоминает как финальные: в таблице правил суффиксов это колонка `Kept`.

## Масштаб и проверка { #scale }

Без масштаба Line и Area не записываются. Масштаб живёт у листа, а не у позиции.

1. Инструмент `Scale` (`S`): провести по размерной цепочке или габариту с подписанным размером, ввести длину. Принимаются `1/8" = 1'0"` и `1:96`.
2. Проверить вторым размером инструментом `Ruler` (`R`): рулетка показывает длину без записи в дерево.
3. Для нескольких листов сразу: выделить в Pages, `F4`, ввести масштаб один раз. Внизу окна поле `Scale: 1:N`, `Set` и `Presets` для типовых значений.
4. Лист с несколькими масштабами калибруется по той зоне, где меришь; увеличенные фрагменты лучше вынести копией листа в `Arch/unlarged`.

| Лист | Обычный масштаб |
| --- | --- |
| Планы этажей | `1/8" = 1'0"` (1:96), у маленьких домов `1/4"` |
| Планы юнитов | `1/4" = 1'0"` (1:48) |
| Разрезы | `3/8" = 1'0"` |
| Детали | NTS, масштаб не нужен: мерят по размерам в тексте |

!!! warning "Подпись листа не доказательство"
    Structural-листы бывают подписаны `1/8"`, а напечатаны в `3/16"`. Автомасштаб и ручной выбор проверяются по размерной цепочке на самом листе. Все ошибки по листам: [Частые ошибки](../start/common-mistakes.md#pages).

## Точки W/F/S/U { #dots }

<figure markdown>
  ![Точки W/F/S/U под заголовком Scale и статус Route](../assets/images/ourplancore/v3/sheet-dots.png)
  <figcaption markdown="span">Строки W, F, S по этажам B, 1-5, L, R и одна точка U. Выбранная точка подписана в статусе: `Route: W 1st`.</figcaption>
</figure>

Под заголовком Scale на листе стоит сетка точек. Одна выбранная точка решает, в какую папку корпуса ляжет каждый **новый** замер с этого листа, любым инструментом.

| Строка | Для каких листов | Куда идут новые позиции |
| --- | --- | --- |
| `W` (walls) | архитектурные планы `a101 1st` | `walls/<этаж> floor walls`; Area и J Area в `sqfts` |
| `F` (framing) | structural планы `s201 2nd` | `framing/<этаж> floor framing/...` по инструменту |
| `S` (shear) | копии планов под shear walls | `shear walls/<этаж>/shear`, Count в `.../holdowns` |
| `U` (units) | планы юнитов `a3011 u` | `units`, любым инструментом |

Как точка ставится:

- **Сама по имени листа** при `Name`, `F2`, `Batch Rename`, `Page Setup` и на приёме: буква `a` плюс тег этажа даёт W, `s` плюс этаж даёт F, последний тег `u` даёт U (`a3011 u`, `S0-4A U`, копия `... U (2)`; `a301 u el` точку U не получает). Листы с тегами `rcp`, `el`, `sec`, `d`, `demo`, `sch`, `n`, `wt`, `ft`, `fin` и подобными пропускаются. Поставленная руками точка не заменяется.
- **Руками**: щёлкнуть нужную точку; повторный щелчок снимает. Копия плана под shear walls получает S руками.
- **Для всего проекта**: `Settings > Sheet Takeoff Routing > Route sheets without a dot now`.

Сетку можно спрятать галкой `Viewport > Sheet routing`; привязки при этом продолжают работать. `Record` продолжает выбранную позицию и точку не слушает. Полная таблица назначений по инструментам, правила по имени и что делать при ошибочном маршруте - [Имена и автомаршрут](takeoff-naming.md#sheet-dots); настройки строк и этажей - [Маршрутизация: настройки](ourplancore-routing.md).

## Видимость, закладки, слои

| Что | Как |
| --- | --- |
| Спрятать все замеры листа | точка слева от листа в Pages (подсказка `Hide all current takeoffs on ...`); новые замеры остаются видны |
| Спрятать одну позицию на листе | выделить сегмент или строку в Takeoffs и `H` ([дерево](ourplancore-takeoffs.md#hide)) |
| Закладка | `B`, затем `K` добавляет закладку на текущий вид; вкладка `Bookmarks`: `Enter` открывает, `Delete` удаляет; закладки можно пристыковать под Pages |
| Слои PDF | вкладка `PDF Layers`: `Load` читает слои листа, `All On` / `All Off`, `Clear Hi` снимает подсветку, `Layer Trace` обводит по выбранному слою, `Full` меняет затемнение, `Apply` |
| Наложение листов | вкладка `Overlay`: S-план поверх A-плана с подгонкой; для всех этажей `Page > Batch Overlay` |
| Пустой лист, кропы, маска | `Page > Blank Sheet`, `Crop to Sheet`, `Annotation > Hide` |

Слои, наложения, кропы и маска подробно: [Листы: кропы, маска, наложения, легенда](ourplancore-sheets-advanced.md).

## Частые ошибки

- `f` дописан к плану этажа (`a101 1st f`): `f` только у фундамента.
- Тег не последний (`a3011 u el`): точка U не ставится, сортировка по суффиксу путается.
- Масштаб принят по подписи листа без проверки размером.
- Копия листа под каждый тип замера: копии нужны только под shear walls, второй уровень на том же листе, другой корпус и новый комплект.

Все ошибки по листам и дереву: [Частые ошибки](../start/common-mistakes.md#pages).
