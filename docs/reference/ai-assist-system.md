# ИИ-помощь в работе эстиматора

Здесь: где ИИ помогает в текущем процессе, что он делает хорошо, что остаётся за эстиматором и как проверять результат. ИИ ускоряет чтение комплекта и рутину в книге; решение и ответственность за количества - у эстиматора.

## Где ИИ есть сейчас

| Шаг | Что делает ИИ | Что проверить |
| --- | --- | --- |
| Приём проекта | разбор PDF: номера и типы листов, scope, сводка листов, список "Проверить", черновик нот шапки | номера листов и масштаб; шаблонные ноты против scope |
| Имена листов в OurPlanCore | распознаёт штамп при команде Name, предлагает номер и тег | тег последним (`a101 1st`, `s101 f`), `f` только у фундамента |
| Кропы деталей | AI Crop Notes: текст и заметка по кропу детали | марки, размеры, слои по исходному листу |
| Терминалы агентов в программе | встроенные терминалы и Agent Bridge: агент видит открытый проект, может создать и поправить замеры, дерево, имена | каждый новый замер глазами на листе; цвет и символ у новой позиции |
| Книга Excel | вставка строк и нот по правилам, блоки копией эталона, проверка длины нот и округления, черновик `Changes.txt` для ревизии | processed `.xlsx` сверить с `.xlsm`; ноты по [правилам](standard-notes.md) |
| Текст ноты | `Y_Improve_Note` в Excel переписывает ноту по образцам листа `Standarts` | живая фраза, `per <лист>`, длина до 100 |
| Проверка сданного | сверка книги с чертежами: пропуски, задвоения, формулы в чужой блок | каждое замечание открыть на листе, не править вслепую |

## Как просить

1. Дать scope, лист и масштаб: "S201, 3/16", балки второго этажа".
2. Просить список с источниками: марка, размер, лист и деталь, что неясно.
3. Переносить только проверенное; допущения оформлять нотами `assumed; verify`.
4. Похожий сданный проект - подсказка для пропусков, не состав нового.

## Что не переносить вслепую

| Данные | Почему |
| --- | --- |
| Коды балок, перемычек, стоек (`H5`, `B2`, `C5`) | per-project: легенда из schedule этого комплекта |
| Wall types, holdowns, hangers, шаг анкеров, insulation, обшивка | читать в schedules и деталях своего проекта |
| Значения шаблона (`Zip Tape`, `29 oz` adhesive, `Tyvek`) | подставляются по спецификации, не остаются по умолчанию |
| Количества из похожих домов | только как проверка порядка величины ([Ориентиры](quantity-benchmarks.md)) |

## Правила для ИИ в этой базе

- Цитировать номер листа или детали, не страницу PDF; нет источника - `assumed; verify`.
- Не выдавать открытый вопрос за исправленное; не придумывать модели крепежа: условия нет в таблицах - `TBD` с нотой.
- Читать всю строку книги, включая рабочие зоны справа ([DFL](dfl-overview.md#zones)).
- Новая правка владельца становится правилом здесь и в каноне правил, а не остаётся в переписке.
