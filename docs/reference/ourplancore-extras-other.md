# Прочее: закладки, калькулятор, окна листов, шаблоны, импорт

Здесь: небольшие функции, которые включены по умолчанию, но в замере E-Wood почти не используются: Bookmarks, Quick Calculator, открепленные окна листов и `Tile M2`, вкладка Templates, импорт PlanSwift и PDF Takeoffs. Каждая описана коротко: что делает, где кнопка, когда может пригодиться.

## Bookmarks: закладки { #bookmarks }

Модуль Bookmarks (включён). Закладка запоминает лист и положение вида, чтобы вернуться к месту на большом плане.

| Действие | Как |
| --- | --- |
| Добавить закладку на текущий вид | `B`, затем `K` (последовательность, до 0.9 с между нажатиями) |
| Список | под-вкладка `Bookmarks` в панели Pages (`Bkm`): колонки `Name`, `Page`, `View` |
| Открыть | `Enter` или двойной клик по строке |
| Удалить | `Delete` |
| Пристыковать под Pages | кнопка в заголовке вкладки; обратно - `Return Bookmarks to the tab list` |

Закладки хранятся в проекте (`bookmarks.json`). Кропы-закладки с PNG создаёт модуль AI (`Save AI crop here`, `AI Crop +` в консоли ИИ); выбранная закладка попадает в контекст терминала ИИ ([консоль](ourplancore-ai-console.md#context)). В обычной работе роль закладок играют вкладки открытых листов и `F` (вписать лист).

## Quick Calculator { #calculator }

Модуль Quick Calculator (включён). Кнопка калькулятора на правой командной полосе (команда палитры `Quick Calculator`) выдвигает панель `Calculator` слева от полосы: обычные действия и строка `Feet + inches + fraction` с результатом в десятичных футах (`= 9.09 ft`). Удобно перевести `9'-1 1/8"` в `9.09` для имени стены, не выходя из программы. Закрывается той же кнопкой или крестиком панели.

## Открепленные окна листов и Tile M2 { #detached }

Модуль Detached Sheets (включён). Лист можно открыть не вкладкой, а отдельным окном и вынести на второй монитор.

| Кнопка | Где | Что делает |
| --- | --- | --- |
| `Open > Open as Tabs` / `Detach to windows` | заголовок Pages | открыть выделенные листы вкладками или отдельными окнами |
| `Tile M2` (точка рядом - вертикальная раскладка) | заголовок Pages | открыть выделенные листы окнами и разложить по второму монитору |
| кнопка закрытия с меню | заголовок Pages | `Close every other sheet tab and all detached windows...`, `Close all detached sheet windows on monitor 2` |
| `Detach`, `Tile M2` | Sheet Manager | то же из таблицы листов |

В открепленном окне работают все инструменты, включая Beam и Openings, копирование `Ctrl+C` / `Ctrl+V` между окнами и `Ctrl+Z`. Клик по открепленному окну делает его целью навигации Pages: выбор позиции в дереве открывает лист в нём. Группы легенды и маска показываются одинаково в главном окне, открепленном и в PDF.

## Similar по всем листам { #similar }

Инструмент `Similar` ищет одинаковые символы по образцу; галка `Search all sheets in this job` расширяет поиск на весь проект (до 80 листов за прогон). Шаги, пороги и ловушки: [Правка и привязки](ourplancore-editing.md).

## Templates: заготовки деревьев и позиций { #templates }

Модуль Takeoff Templates (включён). Вкладка `Templates` рядом с `Takeoffs` и `Estimating` (стыкуется и под Pages кнопкой `Pop Templates out into a panel docked below Takeoffs`) показывает дерево заготовок: папки и пресеты позиций Line, Area, Count с именем, типом и цветом.

| Действие | Как |
| --- | --- |
| Создать позицию из пресета | ПКМ по пресету > `Create New Takeoff`: позиция создаётся в выделенной папке Takeoffs с именем и свойствами пресета |
| Править заготовки | раскрыть `Edit`: `Folder`, `Line`, `Area`, `Count` добавляют узлы; `Edit`, `Dup`, `Del`; `Reset` возвращает встроенный набор |
| Сохранить для проекта | `Job` пишет копию дерева в проект, `Clear` возвращает глобальное |
| Настройки | `Settings > Takeoff Templates`: тот же редактор с режимами Auto / COM / EWP |

В работе E-Wood дерево строит `More > Auto Tree` по COM-шаблону, а имена позиций несут числа из чертежа (`ext 2x6 9.09`), поэтому пресеты с фиксированным именем нужны редко: разве что для повторяющихся Count вроде марок крепежа.

## Импорт PlanSwift и PDF Takeoffs { #import }

Оба импорта нужны для старых работ; новый проект E-Wood начинается с PDF ([проекты](job-creation-storage.md)).

| Маршрут | Что добавляется | Куда |
| --- | --- | --- |
| `Main > PlanSwift` | отдельный конвертер: папка старой работы PlanSwift становится новым проектом OurPlanCore | новый проект |
| `Main > Open / Import > Import into the current job > PlanSwift project...` | листы и позиции старой работы в открытый проект; исходная папка только читается | группа `01. planswift` в Pages и Takeoffs, отчёт импорта |
| `Main > Open / Import > Import PDF Takeoffs...` или `Main > PDF Takeoffs` (`Page > ADD > PDF Takeoffs`) | PDF с чужими замерами-аннотациями: программа сканирует файлы (с подпапками), показывает найденные линии, площади, точки и рулетки, спрашивает новый или текущий проект | группа `from pdf`; отчёт `import_reports/pdf_takeoff_import_<дата>.md` внутри проекта |

Формулы Item и Note из PlanSwift не переносятся ([известное ограничение](ourplancore-ideas.md)); имена позиций после импорта приводятся к канону руками. Откат любого импорта: `Open / Import > Undo Last Page Operation`.
