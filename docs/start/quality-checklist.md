# Проверка перед сдачей

Чек-листы по разделам в порядке меню "Работа". Проходи целиком перед каждой
сдачей; на полную проверку закладывай 30-60 минут, особенно на позиции,
которых много. Что именно находили на проверках и как это выглядит -
[Частые ошибки](common-mistakes.md).

## Общее

- [ ] Масштаб проверен по размеру на каждом мерном листе, не по подписи.
- [ ] Arch, Structural, specs, schedules, wall types, RCP прочитаны до массового замера.
- [ ] Scope проекта (`Frame`, `Wall panels`, `EWP by others`, `NO metal`, `EXT`) понят и отражён в шапке DFL.
- [ ] Каждый этаж записан отдельно; одинаковые этажи отмечены нотой, но материалы перечислены.
- [ ] У каждой позиции в дереве свой цвет; имена по канону [дерева](takeoff-structure.md).
- [ ] Ничего не задвоено: одна позиция не попала в две ветки (стена в `units` и в `walls`, canopy в `eve` и в `canopy`).

## Стены {#walls}

- [ ] Тип каждого участка (ext, corridor, demising, unit, furring) взят с wall schedule, не назначен группой.
- [ ] Высота стойки рассчитана по разрезу: floor-to-floor минус subfloor, перекрытие, plates. Exact heights записаны (`9'-1 1/8"`).
- [ ] P.T. plate только на бетоне и кладке; двойная нижняя plate только там, где показывает деталь.
- [ ] Bearing walls: plies и шаг из stud schedule своего этажа; лишние plies отдельной строкой Extra.
- [ ] Corridor 2x4 staggered = два ряда по 16", plates 2x6.
- [ ] Shaft walls записаны, материал определён (CMU, shaftliner, дерево); мусоропровод не пропущен.
- [ ] Metal studs: посчитаны с gauge или нота `by others` по правилу клиента.
- [ ] Wall panels: стены под бетоном, внутри existing frame, короткие и наклонные посчитаны stick; exterior build-up walls проверены по конструкции и scope, а не исключены из panels автоматически; соседство с CMU не повод для optional stick.
- [ ] FRT по типу конструкции: Type III - всё в плоскости наружной стены FRT, LVL/PSL там нет; если наружная стена FRT, то blocking и parapets тоже.

## Проёмы {#openings}

- [ ] Одна точка на физический проём, размер = изделие из schedule (не отметка верха).
- [ ] Storefront один раз; окно и дверь под одним header - один opening.
- [ ] Проёмы вычтены из обшивки, WRB, утеплителя и линии анкеров один раз, по своему этажу; окна меньше 4' не вычитаются.
- [ ] Двери шире 4' записаны как двойные; материал и fire label указаны.
- [ ] Jamb blocking у окон и межкомнатных дверей; blocking вокруг окон при Zip R или insulation.

## Обшивка {#sheathing}

- [ ] Каждая сборка дочитана до всех слоёв (ZIP-R по типам фасада, второй слой gypsum, cover board, Z-girt).
- [ ] Наружная обшивка по Arch и energy notes, внутренняя по Structural; расхождение записано нотой с обоими источниками.
- [ ] Название продукта как в проекте; наружный барьер назван WRB, продукт из спецификации.
- [ ] Shear walls: число сторон по schedule; на panel-job одна сторона в панели; `P` = perforated.
- [ ] Floor-height FRT полосы 2' или 4' по периметру своего этажа; box sheathing, truss heel, gables, parapet (inside = outside минус insulation board) посчитаны.
- [ ] Underlayment, sound membrane, 3/4 ply под ваннами, новый subfloor поверх существующего (если деталь требует).
- [ ] Roof sheathing по уклону с листа, коррекция один раз; H-clips только square edge, по шагу опор и модели клипсы.
- [ ] Измеренная площадь дошла до Excel и обновлена после правок.

## Перекрытия и крыша {#floor}

- [ ] Каждая марка балки на каждом этаже; посты и PSL под балками по schedule; пост один раз на верхнем этаже, который держит.
- [ ] Joists только J Area: направление, шаг, end joists, отверстия; длины разложены парами N / L.
- [ ] Rim: продукт по спецификации (`11-7/8" Rim`, `LSL Rim`), в LFT с фактором; rim у roof TJI тоже.
- [ ] Hangers на оба конца, по сборкам, модель по детали; Zmax снаружи и на P.T.; DHU только над стенами лестниц, лифтов и шахт.
- [ ] Ties по всем линиям опирания, шаг = шаг ферм; truss bracing на всю площадь под крышей.
- [ ] Ledger и крепёж по своему этажу отдельными строками; болты, шайбы, гайки раздельно.
- [ ] Blocking: два ряда для стен 10' и выше; drywall ledger; kitchen 2x6 4 по 14', bath 1 по 14'.
- [ ] Лестницы умножены на число лестниц; stringers по детали.
- [ ] Draft stop на чердаке отдельной строкой; piggyback sleepers; flat roof curb blocking `(2) 2x6 P.T.`, если ничего не указано; densdeck или cover board на flat roof.
- [ ] Eaves все участки; canopy и porch не в eve/rake; dropped soffits по RCP.

## Площади, deck и porch {#sqft}

- [ ] Площади по реальному контуру; балконы и porch отдельными строками Front Page.
- [ ] У каждого блока балкона и porch свой множитель, формулы от своего заголовка; porch считан независимо от балконов.
- [ ] Railing: система (composite) или поэлементно (wood painted), не смешано; посты на улице P.T.
- [ ] Porch: ceiling joists, ledger, hangers; каркас не показан - нота `assumed; verify`.

## Shear walls и holdowns {#holdowns}

- [ ] Модель holdown по SW schedule своего корпуса и этажа; к бетону один, через деревянное перекрытие два.
- [ ] Анкеры по шагу и по SW, тип из детали; washers по таблице; двусторонний SW - двойная анкеровка.
- [ ] A35 и прочий крепёж SW только там, где требуют notes или details.

## Excel DFL и ноты {#excel}

- [ ] Формулы от собственных входов блока; первая строка каждой новой формулы проверена; 1.1 не применён дважды.
- [ ] Скопированные блоки: ссылки на свой этаж, detail labels поправлены.
- [ ] Единицы: `LFT` для досок, `pcs` для крепежа, SF для листов; подпись совпадает с расчётом.
- [ ] Ноты: главные в шапке, локальные в своём блоке; живая фраза, до 80 знаков, `per <лист>`; у optional есть причина; нота не противоречит строке.
- [ ] Шаблонные ноты сверены со scope (`Walls are panels by others` только при panel scope); нулевые и неиспользуемые строки удалены.
- [ ] Front Page: Customer, Date, Total pages, площади по этажам, porch и balcony.
- [ ] Другой сорт или материал отдельной строкой (MSR, P.T., FRT).

## Сдача {#delivery}

- [ ] Проект OurPlanCore сохранён; PDF только листов с замерами, на каждый корпус свой.
- [ ] Processed xlsx сделан после последней правки, ноты и строки на месте.
- [ ] Ревизия: `Changes.txt` заполнен (`Changes` и `Open items`), каждый пункт подтверждён листом нового сета; открытое не выдано за исправленное.
- [ ] Ревизия: сравнение "было / стало" с прошлой сдачей по Excel и PDF: что добавлено, что удалено, формулировки нот.
- [ ] Папка сдачи названа как папка клиента при приёме; исходные чертёжные PDF не отправлены.

## Проверка с помощью ИИ

Готовый DFL можно отдать на дополнительную сверку помощнику: секции по scope,
пропущенные строки, количества с сомнительными единицами. Принимай только
конкретный отчёт со ссылками на листы и проверяй его руками; ручной чек-лист
остаётся обязательным.
