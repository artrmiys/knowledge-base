    3D-крыша¶

    Здесь: как из площадей скатов и карнизов получить объёмную крышу во вкладке 3D, задать уклон рёбрам, достроить свесы и стропила и забрать из модели длины ridge, hip, valley и eave в дерево Takeoffs. Нужно на сложной крыше (L, U, несколько уклонов, dormer), когда по плану не видно, где пройдут hip и valley, и когда клиент просит длины рёбер. Простая двускатная крыша меряется без 3D: Area по скату с уклоном в имени (Roof). Стены в 3D, общий вьюер и архивный Massing - 3D и Massing.

    Как устроена модель¶

    Понятие Что это Откуда берётся
    Roof Base контур крыши в плане, основа модели выделенные Area: rf 6, rf mtl 4, flat из sqfts, или любая площадь с листа
    Edge, ребро сторона контура; у ребра свойства Defines Slope, Pitch, Overhang создаётся вместе с Roof Base, по одному на сторону контура
    Eave ребро с Defines Slope: от него поднимается скат с заданным уклоном задаёшь сам или Auto ставит всем
    Rake ребро без уклона: фронтон, торец снять Defines Slope
    Roof Mesh, группа сгенерированная крыша одной базы; у проекта может быть несколько (основной дом, гараж, dormer) каждая Roof Base даёт свою группу, активная выбирается в списке Roof Mesh
    Ridge, Hip, Valley швы между скатами считает Generate Roof
    Rafters стропила по граням Pick Faces или Whole Roof

    Модель хранится в проекте (3D_Context/walls_model.json) и переживает закрытие; цвет ската берётся из цвета исходной позиции Area. Генератор строит крышу "по контуру" как Revit: каждое eave-ребро поднимается со своим уклоном, рёбра встречаются в hip и valley на одной высоте. Крыша остаётся черновиком для проверки: окна, скаты второго порядка и вырезы он не знает.

    Как построить крышу по площадям скатов¶

    Зачем: увидеть ridge, hip и valley на сложном контуре и получить их длины. Нужно: модуль 3D включён (Settings > Modules), на плане кровли есть Area скатов с масштабом листа.

    Путей два. Auto сразу строит полную вальмовую крышу: все рёбра контура становятся eave с одним уклоном. Roof Base создаёт только контур, а уклоны рёбрам задаёте сами. На одной площади берите один путь: Auto с выделенной площадью всегда создаёт новую группу, и после Roof Base по той же площади в модели окажутся две крыши.

    Быстрый путь, Auto:

    1. Откройте лист a105 rf и выделите площади скатов на листе инструментом Select (или позиции rf 6, rf mtl 4 в Takeoffs).
    2. Откройте вкладку 3D и впишите уклон по умолчанию в поле Default боковой панели: 6/12, 4 или 0.333.
    3. Нажмите Build > Auto. Статус: 3D Auto Roof: Roof 1, full hip from N eave edge(s), pitch 6/12, generated M roof mesh face(s).
    4. Для фронтонов переключите нужные рёбра на Rake (ниже) и нажмите Generate Roof.

    Ручной путь, Roof Base:

    1. Выделите площади скатов, как в шаге 1 выше.
    2. Нажмите Build > Roof Base (или ПКМ по листу 3D > Create Roof Base from Areas).
    3. Прочитайте статус: 3D Roof Base: created Roof 1, 1 base layer(s), N selectable edge(s). Select slope edges and apply pitch. Контур появился в сцене плоской плитой, все рёбра пока Rake, режим выбора рёбер включён.
    4. Задайте уклон eave-рёбрам (ниже) и нажмите Generate Roof.

    Результат: статус Roof generated: Roof 1, N mesh face(s) с итогами площади и длин, в сцене скаты в цвете позиции, швы одной линией. Viewer > Iso, Top, Front, Fit поворачивают камеру.

    Советы

    • Auto без выделения берёт все позиции rf и roof проекта и строит из них новую группу. Если таких позиций нет, но Roof Base уже создана, Auto ставит всем её рёбрам уклон из Default. Статус select RF/roof area takeoffs first значит, что нет ни позиций, ни базы.
    • Кнопки Auto и Wall пересобирают стены и плиты, а созданные крыши и их настройки рёбер оставляют на месте.
    • Площадь без масштаба листа пропускается со счётчиком в статусе: поставьте масштаб и повторите.
    • Несколько крыш (дом и гараж): отдельная Roof Base на каждую площадь, активная группа выбирается в списке Roof Mesh.

    Как задать уклон рёбрам¶

    Зачем: разные уклоны на скатах, фронтон вместо вальмы, свес нужной ширины. Нужно: Roof Base создана.

    1. Нажмите Build > Select Edge (на листе статус 3D Roof Edge Select: click a roof base edge...).
    2. Щёлкните ребро на листе; Ctrl или Shift с левым или правым щелчком добавляют рёбра к выбору (правый щелчок с клавишей меню листа не открывает). Рядом с ребром открывается окно Pitch (при нескольких рёбрах Pitch x3).
    3. Введите уклон 6/12, 4 или 0.333 и нажмите Enter: ребро стало eave с этим уклоном. Esc закрывает окно без изменений.
    4. Для фронтона откройте блок Roof Edge в боковой панели, снимите галку Defines Slope (eave) и нажмите Save Edge(s); то же делает ПКМ по ребру: 3D > Set Edge as Rake. Обратно: Set Edge as Eave + Pitch 6/12.
    5. Впишите Overhang in (вынос свеса в дюймах, например 12 или 24) и нажмите Save Edge(s): скат продлевается за стену на эту величину.
    6. Нажмите Generate Roof.

    Результат: статус 3D Roof: saved edge properties to N edge(s) и затем Roof generated; в блоке Roof Edge у выбранного ребра видны уклон и свес, фронтонные рёбра не поднимают скат.

    Советы

    • Ошибка invalid edge pitch значит неверный формат: только 6/12, 4 или десятичная доля подъёма на фут.
    • Уклон можно взять с готовых линий карнизов: выделите в Takeoffs позиции eve 24 main и в их меню 3D примените их к рёбрам базы; совпавшие рёбра получают уклон из поля Default (статус matched N roof edge(s) from selected eave line takeoff(s)).
    • Те же действия есть в ПКМ по ребру на листе, подменю 3D: заголовок Roof Edge - <тип> | <уклон>, затем Add Edge to Selection (у уже выбранного ребра Remove Edge from Selection) добавляет ребро к выбору без Ctrl, Set Edge as Eave + Pitch ... и Set Edge as Rake применяются ко всем выбранным рёбрам.
    • Снять выбор рёбер: ПКМ по листу 3D > Clear Edge Selection; выключить режим: Select Edge ещё раз или любой инструмент листа (Line, Select, Pan...).

    Как подвинуть крышу и работать с группами¶

    Зачем: крыша и стены нарисованы с разных листов и не совпали; на проекте несколько крыш; крыша низкого корпуса встала на высоту самого высокого.

    1. Выберите группу в списке Roof Mesh боковой панели (статус 3D Roof: selected Roof 2): уклон, перемещение, сброс и удаление действуют на неё.
    2. Нажмите Move Roof и потащите крышу в 3D-окне: гизмо двигает её по оси, статус dragging Roof 2 on X-axis; движение замедлено для точной подгонки.
    3. Нажмите Reset Pos, чтобы вернуть крышу в построенное положение.
    4. Лишнюю группу удалите кнопкой удаления у списка Roof Mesh; всю крышу вместе с рёбрами снимает ПКМ по листу 3D > Clear Roof Base.

    Результат: крыша сидит на стенах, в списке только нужные группы.

    Как получить стропила и проверить длины¶

    Зачем: прикинуть количество и длины стропил по граням, увидеть глубину сечения под скатом. Нужно: крыша сгенерирована (Roof Base, рёбра, Generate Roof), иначе статус Rafters: generate the roof first.

    1. Выберите в группе Rafters шаг в первом списке (подсказка Rafter spacing o.c.: 12", 16", 19.2", 24", по горизонтали вдоль eave) и сечение во втором (подсказка Rafter member size: 2x6, 2x8, 2x10, 2x12; глубина сечения уходит вниз от плоскости ската, стены подрезаются к низу стропил). По умолчанию 16" и 2x10.
    2. Нажмите Whole Roof для всех граней или Pick Faces и щёлкните грани в 3D-окне, чтобы включать стропила по одной.
    3. Прочитайте статус: Rafters 2x10 @16" o.c.: 86 pcs, 1240 ft (4 face(s)) - 24 @ 18.5 ft, ...: штуки, общая длина и разбивка по длинам.
    4. Сверьте длины с разрезом: длина стропила по скату равна горизонтальному пролёту, умноженному на множитель уклона, плюс свес.
    5. Нажмите Clear, чтобы убрать стропила.

    Результат: стропила видны в сцене под скатами, стены подрезаны к их нижней грани, числа в статусе и журнале 3D.

    Что 3D-крыша даёт в дерево¶

    Зачем: длины швов и площадь скатов как позиции, которые можно проверить и использовать.

    1. Выделите в Takeoffs папку, куда класть результат (иначе позиции лягут в корень или корпус зелёной точки).
    2. Нажмите Roof Qty в боковой панели: вкладка показывает Sloped и Plan площадь в SF, длины Ridge, Hip, Valley, Eave в футах и число граней.
    3. Нажмите Roof Takeoff.

    Результат: статус 3D Roof Takeoff: created N reviewable takeoff item(s) и новые позиции в выделенной папке:

    Позиция Тип Что внутри
    Roof Eave Line рёбра с Defines Slope, длина по плану
    Roof Ridge, Roof Hip, Roof Valley Line швы, которые нашёл генератор
    Roof Area (plan) Area контур базы в плане

    В Notes каждой позиции сводка: Generated from 3D roof. Sloped ... SF, plan ... SF, ridge ... ft, hip ... ft, valley ... ft, eave ... ft. Замеры лежат на том листе, где стоит база, и попадают в его легенду.

    Связь с Excel и DFL: эти позиции - проверка, не замена канона. В книгу идут позиции, которые читает полоса XL: скаты rf 6 из sqfts (кнопка SF считает кровлю по уклону из имени), карнизы eve 24 main и rake 12 main из eves rakes (кнопка E/R, вынос в дюймах из имени). Длины Roof Eave из 3D сверяются с суммой eve, Roof Hip и Roof Valley помогают проверить hip и valley в деталях крыши; после сверки позиции 3D можно удалить или оставить в отдельной папке 3d check, чтобы они не попали в экспорт. Правила замера: Roof, Eve.

    Клавиши режима Roof guide¶

    Для ручных направляющих на листе (когда база не даёт нужный шов): R Ridge, H Hip, V Valley, E Eave, K Rake, P Pitch; Backspace или Ctrl+Z назад, Esc отмена линии или выход. Два клика создают направляющую, Snap и Ortho работают. Полный список клавиш: Горячие клавиши.

    Сценарии¶

    Поменять уклон одной группы
    1. Выбрать группу в Roof Mesh (например Roof 2, гараж).
    2. Select Edge, Shift и клики по всем eave-рёбрам гаража.
    3. В окне Pitch x4 ввести 4/12, Enter.
    4. Generate Roof: пересобирается только эта группа, основной дом не меняется.
    Dormer как дополнительная группа
    1. Нарисовать Area по контуру dormer на плане кровли (rf dormer 8).
    2. Выделить её, Roof Base: появляется Roof 2.
    3. Select Edge: переднее ребро dormer сделать Rake (фронтон), боковые оставить eave с уклоном 8/12, Generate Roof.
    4. Move Roof поднять dormer на основной скат, если он сел ниже; проверить в Iso.
    5. Пересечение dormer с основным скатом генератор не вырезает: valley по стыку мерится на плане вручную.
    Получить стропила и проверить длины
    1. Крыша сгенерирована, в Rafters выбрать 16" и 2x10.
    2. Whole Roof, прочитать статус с разбивкой по длинам.
    3. Сверить самую длинную группу с разрезом; расхождение больше свеса значит неверный уклон ребра или не тот Overhang.

    Ограничения и частые ошибки¶

    • Генератор строит крышу по внешнему контуру: вырезы, второй уровень скатов, пересечение dormer с основной крышей, фасция и честные свесы на hip и valley - в планах (идеи).
    • Контур с самопересечением выпрямляется до выпуклой оболочки: лишние площади в сцене значит кривой контур Area на плане.
    • Разные уклоны соседних eave сходятся корректно, но результат нужно смотреть в Iso: щель вдоль шва - признак ребра без уклона, которое должно быть eave.
    • Roof Base без выделенной площади молчит статусом select area measurements or RF/roof area takeoffs first.
    • Крыша ставится на самую высокую точку модели: верх самых высоких стен, уровня или плиты во всём проекте. В проекте с корпусами разной этажности крыша низкого корпуса повиснет над его стенами: опустите её Move Roof по вертикальной оси (группы) и проверьте в Front.
    • Позиции Roof ... из 3D попали в экспорт Excel: держать их в отдельной папке или удалить после проверки.
    • 3D не заменяет Area по скатам с уклоном в имени: SF в Excel читает rf 6, не Roof Area (plan).
